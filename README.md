# Windows IT Support Labs

Hands-on IT support and systems administration practicals focused on Windows troubleshooting, system maintenance, diagnostics, and problem resolution.

This repository documents my continuous learning through practical exercises performed in a Windows environment.

## Approach

Each lab follows a structured troubleshooting process:

**Inspect → Diagnose → Fix → Verify → Document**

The goal is to understand the problem, identify its root cause, apply appropriate solutions, and verify the outcome.

## Tools & Technologies

- **Windows 11** — Operating system and troubleshooting environment.
